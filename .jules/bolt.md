## 2024-05-18 - CSV Log Export Performance
**Learning:** Checking `isspace()` on a string character before calling `lstrip()` provides a measurable performance boost (~15%) in hot loops like CSV sanitization because it avoids allocating a new string object when no leading whitespace is present.
**Action:** When a function like `lstrip()` or `strip()` is conditionally needed on the hot path (like checking for prefixes that might be preceded by whitespace), verify if the first character is whitespace using `isspace()` before calling the allocation-heavy stripping function. Do not change `isinstance()` to `type() is` in modern Python as `isinstance` is highly optimized in C. Do not change list comprehensions to tuples in hot loops if instantiation speed is a factor.
