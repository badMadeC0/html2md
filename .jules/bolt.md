## 2023-10-27 - Optimized CSV Formula Sanitization
**Learning:** Checking `isspace()` on the first character before executing `lstrip()` prevents unnecessary string allocations for the vast majority of normal strings. This yields a significant performance improvement (~30% locally) for hot-path string operations like CSV sanitization. Replacing tuple `in` lookups with string `in` lookups `in "=+-@"` is also slightly faster.
**Action:** Next time looking to optimize hot-path string sanitization functions, ensure we only allocate new strings or execute complex string operations (`lstrip()`, `startswith()`) when actually required.
