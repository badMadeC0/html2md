## 2024-03-24 - Fast-Path Execution Before String Operations in Python
**Learning:** Checking character membership (`first in set`) or specific character types (`first.isspace()`) is much faster than unconditional evaluation of expensive string operations like `lstrip()` followed by `startswith()` for CSV formula injection mitigation. Furthermore, bypassing `isinstance(value, str)` in favor of `type(value) is str` yields minor performance benefits. Localizing `dict.get` as `get = dict.get` within a hot loop prevents repeated attribute lookup.
**Action:** Always attempt to exit early from loops or string modification algorithms on the "normal" data path before evaluating costly operations. Utilize built-in `type()` tests instead of `isinstance()` when subclass polymorphism check is unnecessary.
